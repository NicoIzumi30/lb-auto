# Aset Foto Inspeksi Demo

Satu foto cover dan delapan foto inspeksi ini dibuat khusus untuk demonstrasi Porsche Macan S 2023 berwarna Carrara White.

Pada form **Sourcing**, gunakan `00-cover-unit.png` sebagai foto cover utama. File ini terpisah dan tidak dihitung sebagai bagian dari delapan foto inspeksi.

Urutan upload pada form:

| Field inspeksi | File |
| --- | --- |
| Depan | `01-depan.jpg` |
| Belakang | `02-belakang.jpg` |
| Sisi kanan | `03-kanan.jpg` |
| Sisi kiri | `04-kiri.jpg` |
| Ruang mesin | `05-mesin.jpg` |
| Interior | `06-interior.jpg` |
| Nomor rangka | `07-rangka.jpg` |
| Odometer | `08-odometer.jpg` |

Spesifikasi seluruh JPG:

- Resolusi: 1448 × 1086 piksel.
- Rasio: 4:3 landscape.
- Format: JPEG.
- Ukuran berada di bawah batas upload aplikasi 8 MB per file.

Foto cover berformat PNG dengan resolusi 1672 × 941 piksel dan rasio landscape 16:9.

File PNG sumber disimpan di folder `source-png`.

Catatan: seluruh gambar merupakan aset sintetis untuk demonstrasi. Jangan digunakan sebagai bukti inspeksi kendaraan nyata atau dokumen transaksi riil.
